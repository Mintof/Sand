# ⏳ Falling Sand — Unity Project

Минималистичный симулятор падающего песка на Unity. При нажатии **единственной кнопки** запускается процесс осыпания: песок, изначально полностью загруженный на заданной высоте от земли, постепенно падает вниз. В проекте реализован жёсткий лимит в **400 частиц** для обеспечения стабильной производительности и предсказуемого поведения симуляции.

## ✨ Возможности
- Запуск симуляции одной кнопкой в интерфейсе
- Плавное, пошаговое падение частиц
- Начальное состояние: песок расположен на фиксированной высоте от поверхности земли
- Жёсткое ограничение: максимум **400 активных частиц** одновременно
- Оптимизированная работа с пулом объектов (без аллокаций в runtime)

## 🛠 Требования
- **Unity:** 2022.3 LTS или новее
- **C#:** 10+
- **ОС:** Windows / macOS / Linux
- **Минимальные требования:** GPU с поддержкой OpenGL 4.5 / DirectX 11, 4 GB RAM

## 🚀 Как запустить
1. Клонируйте репозиторий: `git clone <url>`
2. Откройте папку проекта через Unity Hub
3. В редакторе перейдите в `Assets/Scenes` и откройте сцену
4. Нажмите ▶ **Play**
5. Нажмите кнопку **«Запуск»** (Start) в интерфейсе сцены — песок начнёт постепенно осыпаться

## 🎮 Управление
| Элемент | Действие |
|--------|----------|
| Кнопка `Start` | Запускает процесс падения песка |
> ⚠️ В проекте **нет других клавиш, меню или UI-элементов**. Симуляция управляется исключительно одной кнопкой.

## 💡 Советы по настройке
- **Лимит частиц:** Значение `400` задано в скрипте-контроллере. При необходимости его можно изменить в публичном поле `MaxParticles`, но рекомендуется не превышать `600–800` для сохранения стабильного FPS.
- **Скорость падения:** Регулируется через параметр `DropInterval` / `GravityScale` в инспекторе скрипта.
- **Производительность:** При достижении лимита новые частицы не спавнятся, пока старые не коснутся земли или не будут удалены. Это предотвращает просадки FPS и переполнение пула.

## 📦 Сборка (Build)
1. `File → Build Settings`
2. Добавьте текущую сцену в список
3. Выберите платформу (**PC, Mac & Linux Standalone** рекомендуется)
4. Нажмите `Build` → запустите полученный файл. Кнопка запуска будет работать сразу после открытия приложения.
